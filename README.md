# My Journal 🐰

Aplikasi jurnal harian yang lucu: kalender, tugas harian, mood tracker, pelacak minum air, dan pelacak keuangan.

## Isi folder
- `index.html` – aplikasinya
- `manifest.webmanifest` – info aplikasi (nama, ikon, warna) supaya bisa di-install di Android
- `sw.js` – membuat aplikasi tetap bisa dibuka tanpa internet
- `icons/` – ikon aplikasi

## Cara membuka
Upload folder ini ke GitHub, aktifkan **GitHub Pages**, lalu buka link-nya di Chrome Android dan pilih **Tambahkan ke layar utama / Install app**.

Untuk membuat file APK/AAB (Play Store), masukkan link GitHub Pages ke https://www.pwabuilder.com.
